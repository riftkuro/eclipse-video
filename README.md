# Eclipse Video

Eclipse Video is a companion tool for the Eclipse Animator plugin.

https://discord.gg/eclipseanimator

## Install

Windows: download `Eclipse Video Setup x.y.z.exe` from the latest release and run it.

Mac: download `Eclipse-Video-x.y.z-mac-arm64.zip` (Apple silicon) or `Eclipse-Video-x.y.z-mac-intel.zip` (Intel), unzip, and drag Eclipse Video to Applications. The first time, right-click the app and choose Open, or allow it under System Settings → Privacy & Security.

Both update themselves from the releases here.
