# Eclipse Video

Eclipse Video is a companion tool for the Eclipse Animator plugin.

https://discord.gg/eclipseanimator

## Install

Windows: download `Eclipse-Video-x.y.z-Installer.exe` from the latest release and run it.

Mac: download `Eclipse-Video-x.y.z-mac-arm64.zip` (Apple silicon) or `Eclipse-Video-x.y.z-mac-intel.zip` (Intel), unzip, and drag Eclipse Video to Applications. If macOS blocks the first launch, allow it under System Settings → Privacy & Security.
